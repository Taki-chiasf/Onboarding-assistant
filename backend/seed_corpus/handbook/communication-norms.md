# Communication Norms

## Channels
Use public chat channels for work discussion. Direct messages are for sensitive
or personal topics.

## Async first
Prefer async communication. Write up decisions in docs and link them in chat.

## Response expectations
Reply to direct messages within one working day. Notifications do not require
immediate response outside core hours.

## Meetings
Respect meeting agendas and start on time. Decline meetings without a clear
purpose.
